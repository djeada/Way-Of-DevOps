# Lab 02 — Create your product-image store

**Time:** 60–90 min. **Objective:** Create, upload, download and delete objects in an S3-style bucket.

Run everything from `labs/floci` after `docker compose up -d`. Use `./aws-local` to force local, fake credentials. Repeating resource-create commands may report that resources already exist; use existing names or reset the local emulator.

## Hands-on steps

```bash
./aws-local s3api create-bucket --bucket floci-lab-images
printf 'DEMO PRODUCT IMAGE BYTES\n' > /tmp/floci-demo-image.txt
./aws-local s3 cp /tmp/floci-demo-image.txt s3://floci-lab-images/notebook.txt
./aws-local s3 ls s3://floci-lab-images/
./aws-local s3 cp s3://floci-lab-images/notebook.txt /tmp/floci-check-image.txt
cat /tmp/floci-check-image.txt
./aws-local s3api head-object --bucket floci-lab-images --key notebook.txt
```

## Evidence / success criteria

List the bucket and show the downloaded contents are identical. Screenshot synthetic test data only.

## Investigation and extension

1. How does an object key differ from a filesystem path? 2. Add a second product file. 3. Delete only the second object and verify the first remains.
